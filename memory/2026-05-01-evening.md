## Printavo API Gotchas (hardened into SKILL.md)
- `quoteCreate`: use `contact: { id: "..." }` — NOT `customerId`
- `lineItemGroupCreate`: use `parentId` — NOT `orderId`
- Line item sizes for non-apparel: `size: size_other` (not ONE_SIZE, that's invalid)
- ClickUp task close: status `"Closed"` (not `"complete"`) — varies by list
- `customerDueAt`: ISO8601 date only | `dueAt`: full ISO8601 datetime
