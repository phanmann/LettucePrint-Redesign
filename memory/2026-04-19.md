## Flushing Cannabis Co. — POS Update: Carrot (Apr 21, 2026)

### Key Change
POS provider is **Carrot** — not a direct Cova iframe. Carrot wraps Cova on their end and provides a **JavaScript embed** (not iframe).

### How Carrot Works
- Inject two `<script>` tags in `<head>`: sets `CARROT_API_URL` + `CARROT_SPACE_KEY` globals, loads `carrot.js` from `nevada-store-core.getcarrot.io`
- Place `<div id="carrot-store"><div id="carrot-store-root"></div></div>` on the store page
- Carrot is a SPA — all sub-paths must rewrite back to the store page
- No caching allowed on the store page
- CSS caution: avoid `!important` overrides that could bleed into Carrot's styles

### Docs
https://www.notion.so/getcarrot/3rd-Party-Carrot-Store-Setup-Wordpress-Embedded-3dcfdb14c2144b639cd6965d498fa1ef
