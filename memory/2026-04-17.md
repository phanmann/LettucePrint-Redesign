## What Was Built Today

### Artwork Upload & Proof Flow (full pipeline)
- **Pre-payment upload**: `/shop/stickers/checkout`, `/shop/spot-uv/checkout`, `/shop/roll-labels/checkout` — intermediate page between configure and Stripe. Customer uploads artwork, previews it, confirms, then proceeds to Stripe.
- **Shared `CheckoutFlow` component**: `/src/components/shop/CheckoutFlow.tsx` — parameterised by product, supports `theme`, `artworkNote`, `acceptedFormats`, `cancelPath` props. Used by stickers + spot-uv.
- **Roll labels has its own `RollLabelCheckoutFlow`**: `/src/app/shop/roll-labels/checkout/RollLabelCheckoutFlow.tsx` — includes unwind direction picker as required Step 0 before upload.
- **Uploadthing** installed and wired: `artworkUploader` route in `/src/lib/uploadthing.ts`, API at `/api/uploadthing`. Accepts PDF, AI, EPS, PNG, SVG up to 64MB.
- **Artwork stored**: URL passes into Stripe session metadata (`artworkUrl`, `artworkFilename`).
- **Stripe webhook**: `POST /api/webhook/stripe` — `checkout.session.completed` creates/upserts Sanity order, stores artwork URL + shipping details.
- **Sanity order schema**: `/src/sanity/schemas/order.ts` — full lifecycle fields: artwork, proof, status, shipping address, proof token, feedback.
- **Steve email on artwork**: `/api/artwork` + triggered by webhook — Resend email with download link.
- **Proof send**: `/api/proof/send` — generates UUID token, stores on Sanity order, emails customer with `/proof/[token]` link.
- **Proof approval page**: `/proof/[token]` — shows proof image/PDF, approve or request changes with feedback field. Token-based, no login required. Custom not-found page for expired tokens.
- **Proof respond**: `/api/proof/respond` — updates Sanity proofStatus + orderStatus, emails Steve (approve = green, changes = amber).
- **Shipping**: Stripe address collection enabled (US + CA). Shipping rate `shr_1TNM3O0tZDU2TeWtjOcfuAUJ` (live). Test rate created locally. Shipping details stored in Sanity order.
- **Order confirmation page**: Cleaned up — artwork status card in hero (prominent, pulsing dot, "next: proof sent to email"), order summary shows subtotal + shipping + ship-to + total paid. No upload panel (moved pre-payment).

## Decisions Made
- Artwork upload is **required before payment** (no skip option) on all products
- Proof flow: customer approves initial proof online → Steve sends **final proof manually by email** → customer replies OK → production
- Shipping: Stripe-native address collection, calculated at checkout
- Spot UV accepted formats: AI · EPS · SVG · PDF only (more restrictive than stickers)
- Spot UV spot layer note: **yellow (100% Y)** on separate layer
- Spot UV embossing: 1 layer included standard; selector is for extras (0–4 additional)
- Roll labels: unwind direction is **required** before upload — 8 standard directions, visual SVG diagram picker
- Roll labels: Heavy Laminate removed — Matte + Gloss Laminate only
- Per-unit price is the hero number on all calculators
